# 默认模型认证核对

对用户指定的 `https://api.deepseek.com/models` 进行只读 Bearer 认证检查，没有发送对话内容或生成模型回答。

- 分发默认密钥返回 HTTP 200，服务返回模型 ID 为 deepseek-flash、deepseek-v4-pro。
- 本机当前活动配置原为“默认”，它使用另一把 DPAPI 保存的本地密钥，服务返回 HTTP 401。
- 已将本机活动配置改为 DeepSeek Flash，以 DPAPI 保存用户指定的可用默认密钥；保留旧“默认”配置及设置备份。不把仅有模型列表检查标记为工具调用能力验证通过。

配置解析优先采用用户本地凭据，因此分发默认 Key 正确，不代表旧用户配置会自动替换。此前为保留已有用户配置而保留的旧活动项正是本次失败来源。

界面调整：右上角存在重复模型 ID 时附加配置名称，区分不同的端点/凭据 Profile；认证失败提示引导核对具体配置，避免将所有密钥统一当作一个默认 Key。

需要完全退出旧进程并重启，使内存中的活动 Profile 与密钥刷新。诊断脚本位于 artifacts/diagnostics/，只向用户指定官方服务发送凭据，禁用重定向，输出脱敏。本记录不包含 API Key。

# 开发工具接续说明

开始前先读 [Demo 实现设计](DEMO_IMPLEMENTATION_DESIGN.md)。本文可作为交给其他编码工具的启动提示词。

## 通用提示词

```text
请在当前仓库实现 docs/DEMO_IMPLEMENTATION_DESIGN.md 描述的 Win7 AI 办公助手 Demo。

先检查现有代码和仓库指令，说明当前进度，然后执行已分配工作包。
技术基线为 C# / WPF / .NET Framework 4.8，目标运行环境为 Windows 7 SP1。
不要求离线，客户端直接连接可配置公网或指定 IP 的大模型接口。
P0 使用非流式 Chat Completions 与原生工具调用；先完成 CSV 汇总闭环。

遵循设计中的工具名、DTO、错误码、权限限制与验收标准。
不引入现代 .NET、Electron、WebView2、Python、Node 等额外客户端运行时。
不实现任意命令执行，不硬编码 API Key，不跳过 HTTPS 证书校验。
不要覆盖其他工具的未提交工作。接口变更先更新设计并明确影响。

先用 Fake 模型和样例数据完成可重复演示，再接真实模型。
运行本工作包相关测试，最后报告：修改文件、构建方式、测试结果、未验证项。
如果没有 Win7 目标机，明确写“Win7 未实机验证”，不得声称兼容性验收通过。
```

## 分配工作包

从以下提示中选择一个追加到通用提示词后。多个工具同时工作前，应先完成 T01 并确定集成负责人。

### T01：骨架与契约

建立 net48 解决方案、项目引用、Core DTO/接口与 Fake 模型；准备样例 CSV 和固定工具调用序列。保持接口简洁可测试，不先实现真实网络和 WPF 复杂界面。输出契约说明供其他工作包接续。

### T02：模型连接

实现 IModelClient、API 配置、DPAPI 凭据与 HTTP 错误映射。支持完整 assistant tool_calls 和 tool_call_id，验证 base_url 合并、取消及有限重试。使用 Mock HTTP 测试，禁止将真实 Key 写入测试与日志。

### T03：文件与数据工具

实现 WorkspacePolicy、list_files、preview_csv、aggregate_csv、export_summary。严格使用 decimal，落实路径与输入限制、编码处理、公式注入防护和成果幂等。标准样例总额必须为 371.00。

### T04：Agent 控制器

实现模型/工具循环、上下文、状态、预算、取消和工具回执；先使用 Fake 模型与工具替身。确保没有合格成果时不标记成功，完整测试多调用消息顺序和异常路径。

### T05：桌面与集成

实现 WPF MVVM 主窗口、设置、目录授权、任务事件、取消、成果打开；注入 T02～T04。后台调用不可阻塞 UI，提供显眼的 Fake 模式入口，完成标准演示流程。

### T06：发布与验证

构建发布目录和 README；在可用目标机核对 Win7、位数、补丁、TLS 与实际模型接口。保存命令、环境及结果；将不能验证的内容列为未完成验收项，不更改验收标准来掩盖问题。

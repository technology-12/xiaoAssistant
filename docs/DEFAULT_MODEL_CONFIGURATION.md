# 默认模型分发配置

程序默认配置源为 `config/app.defaults.json`，构建时复制为程序目录旁的 `app.defaults.json`，安装包同样携带该文件。按用户明确要求，文件包含共享 API Key；不在本文、日志或诊断中重复展示密钥。

- API 地址：`https://api.deepseek.com`。
- 默认配置：DeepSeek Flash，模型 ID `deepseek-flash`。
- 可选配置：DeepSeek V4 Pro，模型 ID `deepseek-v4-pro`。
- 首次使用无需手填模型地址或密钥，初始进入在线模式。
- 切换方法：点击主窗口右上角模型名称，直接选择 deepseek-flash 或 deepseek-v4-pro；选择后自动保存、右上角立即更新，下一任务使用新模型。当前运行任务保持原模型。菜单底部保留“管理模型与连接设置…”入口。

首次载入会补充默认 Profile，记录配置版本，后续不反复加入用户已删除的配置。已有实际用户配置及其演示/在线选择保留；没有有效模型配置时选择默认 Flash。工作目录授权和模型数据发送授权继续保留。

本地用户保存的 DPAPI 凭据优先于分发默认 Key；清空密钥会记录禁用标记，避免下次启动又自动恢复共享 Key。默认 Key 仅在默认 Profile 的名称、地址和模型匹配时回退使用，修改为其他端点不会自动获取该共享凭据。

当前用户保护仅作用于用户本地保存的密钥，不能保护随包分发的共享默认 Key。持有分发包的人可以读取该密钥并使用其账户额度；需要可控分发时应改用企业网关或个人密钥。

本轮只构建，没有发起真实模型请求或运行测试。模型 ID 按用户指定值写入，未确认服务端的可用性、额度或工具调用能力；界面不预先标记“连接成功”。

# 晓助手 1.0.6：本地 PDF OCR

本版修复扫描 PDF 读取失败：在文本提取之外增加本地 PDF 页面渲染和 Tesseract 文字识别。正式发行入口仍为 .NET Framework 4.8 主线；XP x86/x64 属于单独迁移基线，尚未通过 XP 验收。

## 用户行为

直接要求助手读取、分析或基于 PDF 编写文档即可。`extract_pdf_text`、`read_document_text`、`search_input_text` 和 PDF 成果文字预览共用提取流程。已有文字的普通 PDF 继续走文字层；无文字页自动 OCR；包含较大图像的混合页识别图像内容并保留原有文字层。

随包提供简体中文、繁体中文、英文及方向检测资源，不要求用户安装 Python、Tesseract 或另外下载语言包。OCR 在本机完成，不调用远程 OCR 服务。模型请求仍沿用用户配置的 API。

识别保留原页码。界面状态显示当前页与识别阶段，用户可以取消。识别结果会标注 OCR 来源及低置信度页；混合页按图像层识别时单列已有文字，并提醒核对阅读顺序。复杂公式、表格、手写字和低清扫描件可能出现错漏，不能宣称已准确还原原版排版。

## 实现

- `PdfOcr.cs`：可控页面栅格化、语言引擎、方向检测、逐页置信度与缓存。渲染默认 300 DPI，限制画布最多约 1200 万像素、长边 6000 像素，异常尺寸拒绝处理。
- `PdfText.cs`：统一普通文字与 OCR 正文、页码、置信度和范围说明。原有 10 MiB 输入、200 页、单页 2 万字符及总计 20 万字符的资源限制继续生效，达到限制明确报错，不静默截断。
- 混合页采用带坐标与方向的图像层合成，单独保留原生文字，避免系统字体回退失败阻断读取。图像尺寸和数量有边界；解码失败不返回不完整全文。
- 对普通 8 位 RGB/灰度、无蒙版或特殊 Decode 的 ASCII85+Flate 图像链使用线性 ASCII85 解码及 .NET Deflate；校验 zlib 头、校验和及展开上限，避免原依赖在大幅 RGB 扫描页上解码过慢。其他色彩、预测器与过滤器仍交给解析库。
- OCR 模型与渲染仍在独立 Worker。相关读取工具和内部 OCR 处理统一最长 600 秒，其余工具维持原限制；子任务最长窗口相应允许 600 秒，角色/父任务约束仍可收紧。原任务总预算与进程资源边界保留。
- `ToolProgress` 事件只传页码与处理阶段，不传扫描正文。父宿主持久化并转发进度；子 Agent 进度转为父任务状态。取消和超时通过宿主 Job Object 终止实际 Worker，包括正在执行的原生识别。
- 缓存仅位于任务用户数据内部 `runtime/pdf-ocr/<实现版本>/<源文件 SHA-256>/page-N.json`，保存识别文字、置信度和来源。相同任务后续阅读/搜索复用，不修改 PDF、不交付临时图片。缓存按页临时写入并原子移动/替换；损坏缓存重新识别。清理任务会一并清理其缓存。不同任务/子任务隔离存储。

## 依赖和便携包

NuGet：PdfPig 0.1.9、PdfPig.Rendering.Skia 0.1.9.1、SkiaSharp 2.88.9、Tesseract 5.2.0 及其传递依赖。语言模型来自官方 tessdata_fast 4.1.0；文件来源与 SHA-256 固定在 `assets/ocr/sources.json`，`scripts/Prepare-OcrAssets.py` 可校验或恢复。

保留 x86/x64 SQLite、Tesseract/Leptonica、Skia/HarfBuzz 本机库。便携包的环境检查覆盖 OCR DLL、语言资源和 VC++ 运行库；准备工具可运行随包提供的微软 VC++ 2019 14.29.30157.0 x86/x64 安装器。打包验证安装器微软签名与固定散列，打包过程不安装运行库。首次缺运行环境时用户仍需运行“准备运行环境.cmd”，安装器可能请求系统管理员权限或重启。

根目录仍只有 `晓助手.exe`、`检查运行环境.cmd`、`准备运行环境.cmd`、`首次使用说明.txt` 和依赖文件夹；不包含开发者的聊天历史、配置或 OCR 试卷缓存。默认模型配置沿用既定发行配置。许可与来源随包提供。

## 验证入口与范围

验收源码：`tests/WorkAssistant.Ocr.Tests/Program.cs`；定位用最小探针：同目录 `QuickProbe.cs`。二进制验收复制到独立测试目录，引用本次候选程序集，不初始化产品 App 或共享设置。真实样本只在本机处理，识别正文及原件不放进分发包。

覆盖 x86/x64 原生库加载、原始 10 页扫描试卷、页码顺序、标题与视觉来源核对、置信度、缓存一致性与损坏修复、原生文字快路径、混合图文与标题保留、空白与损坏 PDF、读取分页、搜索、提取范围、真实 Host/Worker 进度与取消。另回归本地内核、子 Agent、办公技能和第七轮办公工作台。实际通过数量、耗时、测试平台与候选二进制散列以包内 `verification/summary.json` 为准，不沿用旧版通过数。

本轮运行环境为 Windows 10.0.26200；Win7 实机和 XP 双平台验收尚未执行。已有文字的 PDF、扫描件和混合页采用不同路径，不能用单一图片识别成功代替完整管线验收。

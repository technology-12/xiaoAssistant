# 项目与对话导航

新版入口：`artifacts/projects-candidate/WorkAssistant.Desktop.exe`。本轮旧候选目录被正在运行的程序占用，因此采用独立目录交付；没有强制终止旧程序。启动新版本前请完全退出旧版本，包括托盘。

## 左侧结构

- 新对话：开始独立对话，快捷键 Ctrl+N。
- 搜索项目和对话：按项目名称、说明及对话标题筛选，不逐键访问数据库。
- 技能工作室：继续提供现有技能及创建器。
- 项目：使用 `+` 新建；箭头展开项目内对话，点击名称打开项目的新对话空间，选中项目显示高亮。
- 最近对话：按日期分组显示未归入项目的对话。旧版本对话没有 ProjectId，自动按独立对话显示，不丢弃。
- 底部：当前工作目录、任务与成果、设置及更多维护选项。“添加文件”位于对话输入区。

## 项目管理

新建项目填写名称、说明和关联目录，不搬动原文件。项目不是一个必须由软件创建或删除的物理文件夹。

项目右侧 `⋯` 提供：新建项目对话、编辑项目、打开工作目录、删除项目。编辑可调整名称、说明和关联目录。目录变更用于未来的新对话，已有对话仍保存原工作目录和成果来源。

**删除项目只删除项目分类。** 数据库在一个事务中将其会话的 project_id 清空，再移除 project 记录。该调用不进入 DeleteTask，不调用目录或文件删除接口。对话移至普通列表；任务、输入快照、工作目录、原件与成果全部保留。删除前有明确确认说明。

## 对话管理

每段对话右侧 `⋯` 可重命名、移入其他项目或移出项目。归类变更不移动文件，也不重写已有对话的 WorkspaceRoot。

“从对话列表删除”只删除会话列表记录，确认框会说明：对应任务记录及所有文件仍保留，可从任务中心查看。它不等同于安全擦除任务历史；如需要清理本地任务数据，应使用任务中心的独立清理功能。

打开旧对话时在后台读取数据，再更新界面。用户可继续发送后续消息，每轮创建新 Task 和新输出目录，不自动重跑旧步骤。待复核的文件变更对话保持输入/重试限制，需先查看任务中心；新对话可以开展新的明确工作。

## 持久化与兼容

新增 `ProjectRecord` 存在原 SQLite documents 表的 project 类别；Session 增加可选 ProjectId 字段。旧数据默认没有项目，schema 仍为 v1，没有删库、搬目录或重建任务。

项目选择记入用户设置的 selected_project_id。会话的目录单独保存，项目重命名或改目录不改写历史来源。侧栏保留最近 100 个独立对话和每项目最近 100 个匹配对话；搜索从全部已存会话元数据中匹配，显示上限不代表删除旧记录。

主要实现：Core/ProjectRecord、Infrastructure/SqliteStateStore 与 LocalTaskStore、Desktop/MainViewModel.Projects、MainWindow.Projects、ProjectEditorWindow，以及 MainWindow.xaml 的项目和对话行模板。

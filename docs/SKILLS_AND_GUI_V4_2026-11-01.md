# 技能工作室、GUI V4 与应用图标

本轮按用户要求去除销售汇总快捷入口，增加应用内技能创建器、再次优化 GUI、补齐应用图标，并统计代码行数。保留通用表格计算底层工具，不再将销售业务作为首页任务入口。旧 `release/` 未覆盖，交付入口仍为 `artifacts/production-candidate/`。

## 技能闭环

侧栏“技能工作室”可以选择已有技能、创建空白技能、导入模型生成的草稿和返回通用助手。当前内置：

| 技能 ID | 显示名称 | 范围 |
|---|---|---|
| skill-creator | 技能创建器 | 询问目标、整理方法、调用 draft_skill 生成可审阅草稿 |
| spreadsheet-assistant | 表格整理 | 预览字段、确认口径、筛选/映射/计算、导出 Excel；不预设销售场景 |
| document-assistant | 文档与模板 | 查看模板字段、填充 Word、基于计算结果生成报告 |
| pdf-extract | PDF 文字提取 | 保留页码和范围，按需生成 Markdown；不冒充 OCR |
| file-organizer | 文件归档 | 先计划，再经确认移动或改名；不确定时停止 |

技能创建器产出 `<id>.SKILL.md` 和 `<id>.skill.json` 到本轮输出目录，**不自动安装**。在技能工作室导入 `.skill.json` 后可审阅并编辑说明和工具列表，点击“保存为新技能”写入用户技能库；已有 ID 不覆盖，内置技能不允许被用户同名技能替换。也可从空白表单手工创建。

演示模式为创建器生成示例草稿；在线模式由用户配置的模型根据实际需求起草。草稿的外部脚本、程序和安装动作不受支持。

应用内技能格式为目录中的 `SKILL.md` + `skill.json`。前者保存 name/description frontmatter 和方法正文；后者保存 ID、显示名称、版本和工具白名单。当前仅支持受控的指令型技能，不会直接运行任意 Codex/Claude 社区技能中的 scripts。

内置目录为程序旁的 `skills/`，随构建复制；用户目录为 `%LOCALAPPDATA%/Win7WorkAssistant/skills/`。技能加载检查大小、ID、版本、元数据一致性及工具白名单。Host 根据选中技能筛选真实工具定义，程序审批、路径、资源和外发目的地规则继续生效；任务记录保存技能 ID 与版本。

## GUI 调整

- 延续用户选择的留白工作室方向，改为鼠尾草绿、暖白和低对比度分隔线，使用统一圆角与更柔和的层次。
- 品牌区统一为“拾光”；首页使用品牌图形、按时段问候和简短工作提示。
- 首页四个入口为创建技能、整理 Excel、PDF 提取、文件归档。技能库中另提供文档与模板能力。
- 首页卡片增加图标底座、留白与按压反馈；系统允许客户端动画时使用 140ms、2px 悬停位移，系统关闭动画时不启用位移。
- 输入框、卡片和技能编辑器沿用共享样式。没有添加模糊、持续背景动画或重阴影来增加渲染负担。

## 应用图标

原创图形为深绿圆角底、暖白文档和金色星芒。源文件：

- `src/WorkAssistant.Desktop/Assets/AppIcon.svg`：可编辑矢量源。
- `AppIcon.png`：应用内品牌图形。
- `AppIcon.ico`：16/24/32/48/64/128/256 多尺寸图标。

图标已连接到 ApplicationIcon、WPF 主窗口与 Inno Setup 配置；托盘继续从 EXE 提取关联图标。安装器脚本有图标配置，但正式签名安装包仍未生成。

## 代码统计与构建

准确统计见 `SOURCE_LINES.md` 与逐文件明细 `SOURCE_LINES.json`。统计脚本为 `scripts/Count-SourceLines.py`。口径是 src 中手写 `.cs` 和 `.xaml` 的物理行数，含空行及注释；不按函数用途剔除 src 内原有演示或内嵌验证辅助代码。tests 目录代码及构建脚本另计。依赖、bin/obj、旧副本、文档与技能 Markdown 不计入生产代码。

本轮仅进行编译、源文件计数与图标资产查看，没有运行应用、单测、GUI 测试、技能行为测试或 Win7 验证。构建结果和文件摘要见候选目录的 BUILD.log、BUILD_INFO.json；不将编译成功作为运行验收。

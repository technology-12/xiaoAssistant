# 晓助手 1.0.2：目录、文件发现、对话交互与大响应

本版继续修复第七轮基线的四项使用问题，不占用第八轮迁移编号。

## 解压目录

一级目录的普通文件只有：检查运行环境.cmd、准备运行环境.cmd、首次使用说明.txt、晓助手.exe。DLL、实际桌面程序、Host、技能、许可证、样例、校验资料和微软离线运行库统一收进“程序文件”。根目录 EXE 是带应用图标的轻量启动器，启动该目录内的实际程序并正确传递参数。

便携标记 `parent-v1` 使实际程序继续使用发行根目录的“用户数据”，不因组件下移而误读旧 AppData。首次解压不含该数据目录，旧版记录不删除也不自动导入。应用仍需要 .NET Framework 4.8；缺少运行库时使用根目录的准备工具。

## 工作区自动发现

实际在线任务在建立原有输入快照后，遍历用户授权的工作区常见文档。文件名与路径匹配用户请求的候选优先；结果保留原始相对位置、文件 ID、摘要与快照路径，模型使用 ID 经现有受控工具读取。无需用户先搬动文件到 inputs，旧 inputs 和“添加文件”入口继续兼容。

同名文件在清单中保留各自位置；系统指导模型不明确时给出选择。原件不变，新文档仍平铺交付到 output。自动发现的外部输入用于读取与生成副本，本次没有扩张为任意工作区原件的就地修改权限。

排除输出、.claude、程序文件、用户数据、常见依赖/版本控制目录、隐藏项、目录链接及已知应用凭据配置；安全句柄读取拒绝越界和硬链接。最多枚举 10000 个文件项、1000 个目录、12 层深度；自动加入最多 100 个文件，单文件 10 MiB，快照合计 100 MiB。不能覆盖的范围会在 discovery 元数据明确报告，不自动绕过限制。实际文件内容仍仅按模型工具请求进入必要上下文。

## 内嵌交互

ask_user 的问题与可选答案直接显示在对话卡片中，支持点击选项或展开自填答案。多问题拥有独立完成对象，已经回答的卡片不能被迟到点击改写；取消任务时取消对应卡片。需要文件操作授权时，同样显示确认/拒绝卡，具体操作与完整差异默认展开，只能明确选择本次允许的选项，任意输入不能代替批准。

模型首次数据发送授权和匿名网关继续确认也改为内嵌卡片；等待确认期间锁定冲突的发送与切换操作。新问题先滚动到问题开头，避免只看到按钮而看不到问题；回答后恢复跟随执行输出。历史仍保留工具回执，重看不会重新启用旧卡片。设置界面和系统文件选择器不属于本次移除的任务问答弹窗。

## 响应大小与预算

旧实现把整个 JSON/SSE 传输流限制为 2 MiB，并将该错误映射到任务预算。现在分别限制：JSON 16 MiB、SSE 64 MiB、可见正文 256K 字符、每个工具调用参数 256K 字符，IPC 帧最多 8 MiB。SSE 正文用 StringBuilder 聚合，避免长回复反复字符串复制。OpenAI 兼容协议与 Anthropic 原生协议均适配。

缺少明确模型额度时，默认输出上限为 8192 tokens；已配置的模型额度和已知窗口优先。实际内容超限返回独立 `MODEL_RESPONSE_TOO_LARGE`，提示分章节/文件生成，完整结束前不执行工具。传输放宽不代表无限预算，也不代表服务端保证接受该额度；模型本身限制仍须在设置中正确填写。

同时修复“不生成文件”中出现“生成”导致错误要求文件成果的问题，避免读取工作区文件成功后被误判 NO_ARTIFACTS。

## 验证与交付

新增 27 项专项检查：嵌套工作区查找、同名位置与优先级、范围上限、快照不可变、实际 Host/Worker 读取、超过旧 2 MiB 的正常 OpenAI JSON/SSE 和 Anthropic JSON 响应、超大正文分类、内嵌回答/拒绝/取消/关联及首次模型授权。此前 464 项检查继续用于回归。构建 0 警告、0 错误。

发行文件为 `artifacts/packages/XiaoAssistant-1.0.2-portable.zip`。实际解压后的根目录清单、启动器、中文空格路径、独立数据和 x86/x64 检查记录在同名 validation.json。测试仅使用合成文档和本地模拟 API，未使用真实 Key 调用模型；Win7 实机和全新系统的运行库安装仍待目标环境验收。

# 按页审阅与修复边界

改编来源：PeterKalmstrom/claude-powerpoint-skill 的 SKILL.md 和 reference/AUDIT.md（MIT，Copyright 2026 Peter Kalmström）。以下是适配后的方法，不是上游完整检测器的移植声明。

## 当前可以核对

- 正文标题是否空泛、与内容是否一致；材料未提供的数据、结论和承诺不新增。
- 相同信息是否在多页重复，长解释是否适合移入讲稿。只移动已经存在或用户确认的内容，不编造支撑数据。
- 已返回文字中的乱码、重复词、标点空格和待确认占位符；逐页核对，不能仅看疑点数量。
- 修改时保存源版本条件、精确定位和原文，保留原文件及未修改部件。新副本的文字继承首个片段样式，不保证混合字符样式不变。

## 需要渲染或专门工具才能核对

文字是否真的越界、字体是否替换、图片是否拉伸、对象是否遮挡、颜色对比、图表标签与数据、阅读顺序及替代文本。当前 inspect_office 不返回这些完整证据，不把项目标为“已检查”。PPT 文字容量预检只能覆盖部分已知文本框，不替代实际渲染。

## 报告写法

每个问题说明页码/形状、证据、建议及是否已修改。无证据时写“待核对”，没有工具时写“未检查”，不是“通过”。只做审阅时不强制生成新版。修改后回读新文件，保留无法解决的问题，不以纯文字检查冒充像素级验收。

上游的 Python、COM、媒体 API、批量自动修复与远程错误报告调用不在迁移范围；不要运行或伪造这些调用。用户要求保留既有品牌和图形时，不用统一文字模板替换整份原稿。

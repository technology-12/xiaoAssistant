# PPT 校读与页面质量

改编来源：darce07/pptx-mit-claude-skill 的设计、校读和视觉 QA 工作流（MIT）。

文字校读：按页通读；核对标题、数字、单位、姓名、术语、重复词、乱码及占位符。proofread_findings 是疑点，不是事实判断或强制自动修复清单。

内容层次：每页围绕一个信息点；标题与正文不矛盾，讲稿承载解释与过渡。长句拆分或移入 notes 后，必须保留重要事实和限定条件，不以“简洁”为理由丢失内容。

版式判断：保持对比、边距和留白；避免密集长段、字体过小或装饰抢占内容。当前引擎可拒绝部分过密文字，但不会测量所有外部模板、图表、占位符和嵌入字体的真实布局。

如果具有真正可用的渲染能力，检查每页裁切、文字溢出、对齐、字体替换与低对比，修正后重查。当前晓助手未提供运行时逐页渲染工具，不能照抄上游 render_slides.py、LibreOffice 或 COM 命令；说明缺失的渲染验收，不把“文件生成成功”当成视觉完成。

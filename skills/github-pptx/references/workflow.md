# PPT 生成与修改路径

改编来源：darce07/pptx-mit-claude-skill（MIT，Copyright 2026 Israel Mosquera）。

先从材料组织页面顺序：背景、核心判断、依据、行动，或用户指定的教学/汇报结构。不把一个常见叙事框架强加给所有任务。

```json
{"file_name":"阅读课件.pptx","slides":[{"layout":"cover","title":"阅读与表达","bullets":["以材料证据解释观点"],"notes":"说明本课的学习目标和资料来源。"},{"title":"先找到支持观点的证据","bullets":["标记关键事实","讨论证据与观点的关系","依据反馈修改短段"],"notes":"结合用户提供的实际材料讲解，不补造案例或统计数据。"}]}
```

当前封面和内容页的字体、间距和色彩由引擎控制，不发送任意 Python、坐标、XML 或未经支持的 layout 类型。每页最多六个短要点不表示应填满六点；用最少信息支撑该页目的。讲稿须与该页内容对应。

编辑现有文件时，先确认保留原设计还是重新组织内容。保留设计选 edit_presentation 的精确文字修改；当前不能把“换主题、插图、图表重绘、改备注”伪装为受支持的文字替换。需要重新组织成新文字稿可用 write_presentation，但必须说明复杂部件不会自动迁入，不退役或删除原件。

成品回读使用 artifact_name，输入原稿使用 path=file_id；两者必须二选一。产生版本冲突、未知定位或文本框容量拒绝时停止套用旧修改，重新读取相关内容后再决定，不擅自覆盖。

# Word 原稿修改与交付校对

改编来源：darce07/docx-mit-claude-skill 的既有文档编辑、proofread 和 regenerate/recheck 工作流（MIT）。

1. inspect_office(path=file_id) 读取实际原稿；分页结果不是全文。明确修改的目标段落与需保留的事实。
2. 使用源哈希、段落编号和完整 expected_text，提供单段 new_text；不猜编号、不全局模糊替换。遇到域、图像、链接、已有修订或复杂控件段落被拒绝时，解释限制，不擅自展平原稿。
3. edit_word 输出新副本，默认保留插入/删除修订。未修改部件保留不等于修改后分页、混合字体和所有字符样式完全不变。
4. inspect_office(artifact_name="修改稿.docx") 回读成品；source_sha256 是该成品的版本标识。检查 proofread_findings，并结合完整正文判断。
5. 核对乱码、相邻重复英文词、标点前空格和未解决占位符。它们可能是合法内容，仅提示复核，不能自动删改。重点复核事实、否定表达、语气、引用和表格内容是否遗漏。
6. 交付新文档与修改清单，说明实际改动和保留事项。需要再次编辑本任务成果时，当前 edit_word 仍要求输入 file_id；先让用户将新稿作为输入重新附加，或按已核对内容另存新版本，不伪造输入引用。

没有运行实际页面渲染时，不能把文本回读或 proofread_findings=[] 当成排版合格证。当前校对检查不包含事实核实、完整中文拼写纠错、自动目录刷新或 Word 页面几何测量。

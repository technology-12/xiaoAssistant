# Word 正文与结构

改编来源：darce07/docx-mit-claude-skill 的创建、表格、分页与校读工作流（MIT，Copyright 2026 Israel Mosquera）。执行代码改为晓助手工具，未移植 Python/COM 依赖。

先确定受众、目的、篇幅、材料与交付格式。新闻稿围绕已确认的事实写标题和导语；教案围绕目标、活动、评价组织结构。用户给定结构优先，不套统一模板。

write_word 的 blocks 示例：

```json
{"title":"阅读教学设计","file_name":"教案.docx","blocks":[{"type":"heading","text":"教学目标"},{"type":"paragraph","text":"说明本课目标与适用学情。"},{"type":"bullet","text":"用材料证据解释观点。"},{"type":"table","rows":[["环节","教师活动","学生活动"],["讨论","追问依据","交流证据"]]}]}
```

表格行列一致，避免把整份教案塞进单元格；长内容拆分为段落或章节。渲染引擎控制字体、间距和表头，不通过连续空格伪装缩进与列。使用 bullet 块表达列表，勿在 text 中额外添加项目符号；当前引擎的具体编号/项目样式由工具决定，不声称具备上游全部列表能力。

上游分页建议关注空白页和标题孤行；本软件尚未暴露分页与自动目录工具，因此不要生成假目录页码或宣称已修复空白页。用户要求严格页数、机构页眉或复杂参考文献样式时，说明当前限制并保留待排版事项。

事实缺失要询问或标注【待确认】，不是为了消除校读告警而补造内容。长稿按可审阅章节组织，受模型、上下文与工具大小限制时明确拆分，不静默截断。

晓助手 1.0.7 · 便携版

【启动】
完整解压到新文件夹，双击“晓助手.exe”。根目录仅有 EXE、两个环境工具和本说明。
“程序文件”内的 DLL、技能、语言资源和许可证必须一并保留。
软件已携带 x86/x64 VC++ 2019 与 UCRT 运行库，不需要安装 VC++，不会将这些 DLL 复制到系统目录。
仍需要系统具备 .NET Framework 4.8。缺少时运行“准备运行环境.cmd”，调用随包的微软签名安装程序，可能需要管理员和重启。
“检查运行环境.cmd”只检查，不执行安装。

【工作区和文件】
默认工作区为“文档\晓助手工作区”，也可以选择自己的文件夹。
可直接说出授权工作区中的文件名或相对位置，助手会递归查找，不要求先放入 inputs。
生成成果直接交付到 output；同名但内容不同的成果会保留不同版本，不覆盖原件。
.claude 保存快照、内部草稿和任务恢复记录，请勿在任务运行中修改它。
聊天记录保存在软件根目录的“用户数据”中。发行 ZIP 不携带既有聊天记录。
再次转发软件请使用原始 ZIP，不要转发使用后的整个文件夹。

【办公和模型】
Word、PPT、Excel、文本与文件操作在本机执行；可选择联网或指定 IP 的模型 API。
模型会收到完成任务所需的提示、文件片段和工具结果，请按实际资料范围授权工作区。
右上角可以切换模型和权限档位。需要补充信息或批准时，在对话卡片中选择。
PDF 文字提取与中英文 OCR 在本机完成，无需 Python、独立 OCR 软件或另下语言包。
识别结果可能有错漏，请核对原页；成果卡提供预览与打开文件。
长任务会整理上下文，原始记录保留；中断写入需复核，不会自动重放操作。

【本版修复与验证】
VC++ 改为随包加载；PDF 增量更新、原生 DLL 位数审计和发布证据一致性已修复。
控制台回归 {console_passed}/{console_total}；界面自检 {ui_passed}/{ui_total}；失败均为 0。
全部计数由实际测试结果生成，二进制散列见“程序文件\verification”。
验证环境为 Windows 10 / .NET 4.8。Windows 7 实机验收尚未完成；本包不是 XP 版。
更多细节见“程序文件\docs\RELEASE_1.0.7.md”。

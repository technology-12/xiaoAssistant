晓助手 1.0.2 · 便携版

【启动】
完整解压到新文件夹，双击“晓助手.exe”。根目录只保留这个 EXE、两个环境工具和
本说明；DLL、Host、技能、样例和许可证都位于“程序文件”。请保持程序文件完整。
缺少 .NET Framework 4.8 时，先运行“准备运行环境.cmd”，按微软安装器提示完成。
应用本身免安装；首次运行会在根目录创建自己的“用户数据”文件夹，不读取旧版历史。

【直接告诉助手文件在哪里】
默认工作目录为“文档\晓助手工作区”，也可以在软件中选择自己的文件夹。
现在无需先把文件搬到 inputs：可以直接说“读取项目资料\本周新闻稿.docx”，
助手会递归查找所选工作区中的常见文档，结合文件名和相对位置匹配，再读取快照。
有同名文件或范围不明确时，助手可在对话中给出文件位置选项供你选择。
请尽量给出具体文件名或子目录；只搜索你授权的工作区，不搜索整台电脑。
为保证速度和本地隔离，会跳过输出、程序、配置、依赖、隐藏及目录链接等目录。
自动发现最多加入 100 个文件；单文件上限 10 MiB，输入快照合计 100 MiB。
如目录非常大或有文件被跳过，工具会向模型报告覆盖不完整，不能假装已经查遍。
自动发现的输入保留原件；生成或修改后的文档直接交付到工作区 output。
inputs 仍然兼容，也可继续通过“添加文件”导入。

【对话内交互】
补充问题和文件操作确认显示在当前对话中，点击选项卡片或填写自己的答案继续。
操作确认卡保留具体内容供展开查看；取消、拒绝或任务中止不会被当作同意。
首次使用模型的发送授权也在对话内确认，不另开窗口。

【响应与预算】
修复了原来把 SSE 传输累计超过 2 MiB 当作任务预算错误的问题。
现在区分传输与实际内容：普通 JSON 传输上限 16 MiB，SSE 传输上限 64 MiB；
正文最多 256K 字符，单次工具参数最多 256K 字符。未指定额度的模型默认预留
8192 输出 tokens（已知窗口或显式设置会优先应用）。超限有明确提示，不执行半截工具。
这并非无限预算；很长的文档仍建议按章节或文件分批生成，模型自身也有额度限制。

【文件、记录与验证】
成果卡提供预览、打开文件和详情；Word/PPT 预览为文字内容，并非页面实际渲染。
旧版记录没有删除，也不自动导入。转发软件请使用原始 ZIP，不要转发使用后的
“用户数据”。用户自己配置的 Key 在换电脑后可能需要重新填写。
不需要 Visual Studio、.NET SDK、Python、Node、Codex 或 Claude Code。
生成 Word/PPT 不要求 Office；本地打开文档需要关联的兼容办公软件。
本包未签名；Win7 SP1 实机和真实模型 API 仍需目标环境验收。
版本、来源、校验及测试记录在“程序文件”内。

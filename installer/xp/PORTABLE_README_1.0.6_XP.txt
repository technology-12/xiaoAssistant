晓助手 1.0.6 · Windows XP 便携版（XP 基线 XP-B1 候选）

【这是什么】
本包是晓助手 Windows XP 独立产品线的第一个基线候选（net40 双平台构建）：
- XiaoAssistant-1.0.6-portable-windows-xp-x86.zip —— Windows XP SP3 32 位
- XiaoAssistant-1.0.6-portable-windows-xp-x64.zip —— Windows XP Professional x64 SP2
两个包能力相同，请按系统位数选择；不要混用两个包写入同一用户数据目录。

【首次使用】
1. 把整个 ZIP 解压到一个新文件夹（不要在压缩软件里直接双击运行）。
2. 双击“晓助手.exe”启动；如果系统缺少 .NET Framework 4 Full，
   会提示运行“准备运行环境.cmd”，按微软安装器提示完成（可能需要管理员和重启）。
   Client Profile 不够，必须安装 Full 版本。
3. 不需要安装 Python、Node.js 或新版 PowerShell；本产品内核完全本地运行。
4. 首次启动会要求选择一个工作区文件夹，程序会自动创建 inputs/ 与 outputs/。

【与 1.0.6 主线（net48）的差异】
- 本包在 .NET Framework 4 上运行，含独立兼容层（调度、上下文、网络传输、
  文件事务、ZIP/OPC、CSV/PDF 解析均为 XP 安全实现）。
- 本地 PDF OCR 不包含在本包内（OCR 依赖的本地库不支持 XP）；
  扫描件 PDF 会明确提示不支持文字识别，不会静默出错。
- 远程 OpenCode 内核在本包中按 XP 产品基线强制关闭，仅保留本机内核。
- 自动更新安装在本包中禁用（XP 构建未配置发布证书，fail-closed）。
- 模型联网：XP 原生 TLS 与现代模型服务不兼容，推荐使用“仅转发模型的网关”
  （指定 IP/域名，HTTPS 由网关终结）；局域网可信网络可用 HTTP。
  证书校验不可关闭，不会自动降级。

【数据与隐私】
- 用户数据保存在包目录的“用户数据”文件夹（便携模式），删除文件夹即完全清除。
- 任务运行时，工作区输入的文件名、表头、预览记录与汇总结果会发送给
  你配置的模型服务；文件读取仅限授权工作目录，输出仅写入 outputs/<任务ID>/。
- 包内不含任何聊天记录、凭据或开发者配置。

【常见问题】
- 启动提示缺少 .NET Framework 4：运行“准备运行环境.cmd”。
- 连接模型失败：XP 系统证书与 TLS 能力有限，请优先使用模型网关地址；
  不提供跳过证书校验的选项。
- Word/PPT/Excel 文档读写完全本地完成；PDF 扫描件不支持文字识别。

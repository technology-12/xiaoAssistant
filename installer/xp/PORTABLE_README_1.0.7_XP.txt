晓助手 1.0.7 · Windows XP 试用候选版

【版本选择与启动】
x86 包面向 Windows XP SP3 32 位；x64 包面向 Windows XP Professional x64 SP2。
完整解压到新文件夹，双击“晓助手.exe”。不要混用两个包的用户数据目录。
需要系统安装 .NET Framework 4 Full，Client Profile 不够。
缺少时运行“准备运行环境.cmd”，调用随包的微软签名安装程序，可能需要管理员和重启。
SQLite 本机组件已随包携带，无需安装 VC++、Python、Node.js 或新版 PowerShell。
“检查运行环境.cmd”只检查，不执行安装。

【使用】
默认工作区为“文档\晓助手工作区”，也可选择已有文件夹。
助手可在授权工作区中查找指定文件，不要求先放入 inputs。
用户成果直接位于 output，内部快照和草稿位于 .claude。
聊天记录保存在软件根目录的“用户数据”。发行 ZIP 不携带已有聊天记录。
模型 API 可联网或访问指定 IP；其他编排、文件操作和文档处理均在本地执行。
XP 的 TLS 和证书能力有限，可使用仅转发模型请求的网关；不会跳过证书检查或自动降级。
Word、PPT、Excel 和文本型 PDF 均在本地处理。XP 包不含扫描件 OCR。
右上角可切换模型和权限档位，审批与补充信息在对话卡片中完成。

【文件修改与中断】
原件修改需要绑定具体版本的批准。写入前保存备份和日志，独占句柄可拒绝并发写者。
XP 采用独占原位写入，不提供事务级原子替换；中断可能需要人工复核，不能保证真实断电时原件完整。
未确认的提交不会自动重放或回滚，应对照任务备份、候选与原件进行复核。

【验证状态】
本平台控制台回归 {console_passed}/{console_total}，界面自检 {ui_passed}/{ui_total}，失败均为 0。
计数来自同一构建的实际测试结果；二进制和审计证据在“程序文件\verification”。
上述测试运行于 Windows 10 / CLR 4.8；net40 构建和这些测试不等于 XP 实机验收。
Windows XP x86/x64 实机、真实断电与旧硬件性能验收尚未完成，release_ready=false。
本包用于试用验证，尚不能对外声称已完成 XP 支持。

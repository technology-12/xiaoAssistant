晓助手 1.0.1 · 第七轮基线体验修复版

【直接启动】
完整解压后，双击本层目录中的“晓助手.exe”，无需再进入 app 等子文件夹。
电脑需要 .NET Framework 4.8 或兼容更新版本；如果提示缺少运行库，请先双击
“准备运行环境.cmd”，它会检测环境并在需要时打开随包附带的微软官方离线安装器。
安装运行库可能需要管理员权限；按提示重启后再次双击“晓助手.exe”。
不要从 ZIP 预览窗口中运行程序，也不能只复制一个 EXE。

【工作文件在哪里】
首次使用默认创建“文档\晓助手工作区”。软件输入区下方始终显示实际完整路径，
点“打开目录”可以直接定位；也可以通过工作区按钮换成你熟悉的文件夹。
待处理文件放入 inputs，或通过“添加文件”选择导入。
交付文档直接保存在该工作区的 output 文件夹，点“输出文件”即可打开。
同名但内容不同的文件会自动变为“文件名 (2).docx”等，不覆盖已有文件或用户修改。
.claude 内部保存任务隔离文件及项目配置，用户通常不需要操作它。

【对话和文件】
输入文字后提示文字立即隐藏；Enter 发送，Shift+Enter 换行。
长回复支持像素滚动，不需要拉大窗口；上翻阅读时不会被后续文本拉回底部。
生成文件后，对话中会显示交付卡片：点击文件名或“打开文件”使用本地应用打开，
点击“预览”只读查看文本或表格，点击“详情”查看路径与校验信息。
Word/PPT 的内置预览是内容预览，并非页面或幻灯片的实际渲染。

【干净的用户数据】
此发行包不会自动读取旧版的 %LOCALAPPDATA%\Win7WorkAssistant。
首次解压使用时，项目和聊天列表为空；该发行目录自己的记录保存在“用户数据”中。
打包按文件白名单收集，不带聊天数据库、个人工作区或用户加密凭据。
软件保留用户此前指定的随附默认模型配置，真实使用仍需模型网络可达且服务额度可用。
不要把使用过的整个文件夹当作干净发行包转发：“用户数据”是你自己的记录，
转发软件请使用本次原始 ZIP。已有旧记录未删除，也没有自动导入新版本。
个人自配 Key 使用 Windows 当前用户加密；换电脑后可在设置中重新填写。

【环境及验证范围】
应用不需要安装 Visual Studio、.NET SDK、Python、Node、Codex 或 Claude Code。
生成/读取 docx、pptx 不要求 Office；要在本地应用打开页面需有关联的办公软件。
支持目标为 Windows 7 SP1、Windows 10/11 的 x86/x64 桌面环境。
本机已做隔离数据、模拟 API、小窗口及解压换路径检查；Win7 实机与真实 API
仍需在目标环境验收。很旧系统的更新、TLS 和证书问题不由便携包自动修改。
这是未签名的便携构建，不是经过代码签名的正式安装器。

程序、Host、本机 DLL、skills、默认模型配置和 prerequisites 请保持完整。
baseline.json、SHA256SUMS.txt 以及 verification 保存基线和检查信息。
